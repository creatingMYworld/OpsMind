How access works

Two permissions, deliberately separate.
resourcemanager.projects.get
Lets OpsMind see a project. Usually granted once as roles/browser at the organization level.
logging.viewer
Lets OpsMind read that project's logs. Granted per project, because log access is not something to hand out organization-wide by default.
